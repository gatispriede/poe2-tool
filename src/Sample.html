Passive Skills in Path of Exile 2 (PoE 2) are a type of Skills. Passive Skills are part of a vast Passive Skill Tree, each class has a Starting Point in the Tree, and players will be able to gain more Passive Skills by spending points on the Skills that are connected to the Starting Point or to Skills that are already obtained. This page covers all the available Passive Skills for Classes and Ascendancy Classes in Path of Exile 2.

 

Path of Exile 2 Passive Skills Guide

Passive Skill Tree in Path of Exile 2

Players can unlock any skill from the Passive Skill Tree by a spending a skill point on a skill connected to their starting point or to already unlocked skills, Passive Skills that grants Attribute, let you select which attribute you want to increase, allowing players to explore the tree in any direction, and you would not be forced to explore any specific direction convinient for your class. The only thing that changes with your chosen Starting Class is that there are 6 starting points in the Tree which are dictated depending on the Starting Class you chose, as all classes share the same tree.

Passive Skills are usually grouped in Clusters with other Skills that are somehow related, for example, by related weapon type. You can "Refund Passives" in order to respec the nodes you chose, in exchange of gold. The refund price depends on the amount of nodes you want to respec, so you don't have to worry about re-spending your whole tree to make a small change.

Weapons Specialization in PoE2

Weapon Specializations require you to spend points from a different pool: Weapon Specialization Points. Which can be obtained by playing the campaign, defeating optional bosses and completing quests.

You can now Dual-Specialize your Passive Skill tree to be able to dynamically swap between two very different types of weapons to keep the synergy between skills and weapon types. You can build 2 different Weapon Sets, and each passive Skill has the option to be used for Weapon Set 1 and/or Weapon Set 2.

You'll find this tab at the upper right corner of your screen from the Passive Skill Tree menu.

Mind the quickness of the swap is relative to the weapon size. There are also Unarmed skills that you might choose to relay on.

 

It's estimated that the count of Passive Skills is about 1800+ Small Passives, 500+ Non-Small Passive Skills and 16+ Keystones.

Path of Exile 2: Nodes

  • Small Passive Skills are the smallest nodes in the Passive Skill Tree, they usually connect to only a few other Skills in the tree, most "routes" in the skill tree are made of  Small Passive Skills that grant minor bonuses, like small increases in stats or attributes.
  • Notable Passives are the medium sized nodes, bigger than Small Passive Skill nodes, they grant greater bonuses, usually connected to many routes to choose from in the Skill Tree, but generally connected with nodes that have similar effects, or are related to the same thing.
  • Keystones are the biggest Nodes. Keystones are Unique and Powerful Passive Skills in Path of Exile 2 whose effect have a significant impact to the character's fight style. 

In-game Skill-Search Feature in PoE2

The Passive Skill Tree is so vast to the point that might be an inconvinience to find a desired skill, or effect related skills, so developers decide to add a search prompt in the Passive Skill Tree interface, that will help you get to what you are looking for. It can be used to find Skills with specific names or to search for effects such as elements, you can even use tag names in the prompt too, useful when reading an effect description you might want to stack up with related skills.

Passive Skill Weapon Swapping in PoE 2

Weapon swapping in Path of Exile 2 introduces a powerful customization feature called dual specialization, allowing you to dynamically allocate Passive Skill Tree nodes that activate based on your equipped weapon set. This system enables you to tailor your passives for specific scenarios. To allocate Weapon Set-Specific Passive Nodes, you’ll need to meet the following requirements:

  • Weapon Set Point Maximum: You must have a Weapon Set Point Maximum greater than 0, which is unlocked as you progress through the campaign.
  • Available Passive Skill Points: You need unallocated skill points that can be assigned to a specific weapon set rather than globally.
  • Weapon Set Selection: You must designate whether the nodes will apply to Weapon Set I, Weapon Set II, or both.

To manage and assign these points, open the Passive Skill Tree menu and look for the dedicated tab in the upper-right corner of the screen. From here, you can allocate points while carefully considering their type:

  • Global Nodes (Gold): Apply universally to all weapon sets.
  • Weapon Set I Nodes (Red): Activate only when Weapon Set I is equipped.
  • Weapon Set II Nodes (Green): Activate exclusively when Weapon Set II is equipped.

This system allows for highly specialized builds, enabling you to assign unique passive benefits to each weapon set and seamlessly adapt to different combat situations.
